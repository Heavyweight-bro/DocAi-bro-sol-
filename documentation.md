# Приховування розділу «Впровадження» та виправлення вибору GPT

## Впровадження лише для розробника

Розділ «Впровадження» був вкладкою в бічній навігації та містив інструкції для розгортання в компанії. Це матеріал для розробника, а не для оператора документів.

1. Текст із `src/components/DeploymentGuide.tsx` перенесено в [docs/IMPLEMENTATION.uk.md](docs/IMPLEMENTATION.uk.md).
2. Кнопку «Впровадження» та посилання «Як підготувати до роботи в компанії» прибрано з `src/App.tsx`.
3. Компонент `DeploymentGuide` видалено; стилі сторінки впровадження прибрано з `src/index.css`.
4. Smoke-тест перевіряє, що кнопки немає в UI.

## Чому GPT-ключ не запускав обробку

Кнопка «Почати обробку» дивиться на **провайдера за замовчуванням**, а не на будь-який збережений ключ. Якщо користувач зберіг ключ OpenAI, але в полі «Провайдер за замовчуванням» лишився Gemini без ключа, `aiConfigured` лишався `false` і обробка не стартувала.

Виправлення в `server/settings.ts`: після збереження ключа, якщо поточний default без ключа, сервер автоматично ставить щойно налаштованого провайдера основним. У UI додано підказку, якщо ключ є в іншого провайдера.
